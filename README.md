# Aura — Personal Reflection Sanctuary & Collaborative AI Companion

A production-ready full-stack web application deploying a personal reflection sanctuary and collaborative AI companion with Google Gemini, Firebase Auth, and Cloud Firestore, architected for high-performance hosting on **Google Cloud Run**.

---

     - 🌅 *Golden Hour Sunset* (rich dusk amber and twilight violet)

6. **Data Sovereignty & Right to be Forgotten**:

10. **Enterprise Zero-Trust Security Audit Modal**:

11. **Daily Epiphany & "Sher of the Day" Banner**:

## 🛡️ Security Architecture & Threat Model

| Threat Zone | Identified Risks | Countermeasures & Architectural Controls |
| :--- | :--- | :--- |
| **Input Surfaces** | Prompt injection, malicious script injection in reflections/snippets | Strict input validation, HTML stripping, React text encoding, and payload sanitization via `stripUndefined` and `sanitizeText`. |
| **Planning & Reasoning** | System instruction bypass, persona jailbreaks | Immutable system prompt boundaries, context-isolated message turns, and server-side validation. |
| **Tool Execution** | API key leakage, unauthorized function calls | Server-side Gemini proxy (`/api/reflect`, `/api/flashback`); Gemini API key is kept strictly in server environment / Secret Manager with zero client exposure. |
| **Memory & State** | Cross-user data leakage in Firestore | Strict path-level security rules (`/users/{userId}/**` restricted to `request.auth.uid == userId`); shared duo rooms (`/duo_rooms/{roomId}`) restricted only to verified participants. |
| **Inter-System Communication** | Insecure snippet sharing, CSRF | Isolated public snippet records (`/public_snippets/{snippetId}`) containing only explicitly selected text with all private chat context stripped. |

### Firestore Security Rules (`firestore.rules`)
```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Isolated User Data
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }

    // Duo Companion Rooms
    match /duo_rooms/{roomId} {
      allow read: if request.auth != null && 
        (resource == null || request.auth.uid in resource.data.participantUids);
      allow create: if request.auth != null && 
        request.auth.uid in request.resource.data.participantUids;
      allow update: if request.auth != null && 
        (request.auth.uid in resource.data.participantUids || 
         request.auth.uid in request.resource.data.participantUids);
      allow delete: if request.auth != null && 
        resource.data.creatorUid == request.auth.uid;

      match /messages/{messageId} {
        allow read, write: if request.auth != null;
      }
    }

    // Public Snippets / Quotes
    match /public_snippets/{snippetId} {
      allow read: if true;
      allow create: if request.auth != null && request.resource.data.authorUid == request.auth.uid;
      allow update, delete: if request.auth != null && resource.data.authorUid == request.auth.uid;
    }

    // Aggregated Telemetry (Zero Journal Content)
    match /system/telemetry {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}
```

## 🚀 Google Cloud Run Deployment Guide

### Prerequisites
- [Google Cloud SDK (`gcloud`)](https://cloud.google.com/sdk/docs/install) installed and authenticated.
- A Google Cloud Project with Cloud Run and Secret Manager APIs enabled:
  ```bash
  gcloud services enable run.googleapis.com secretmanager.googleapis.com
  ```

### Step 1: Configure Secrets in Secret Manager
Store your Gemini API key in Secret Manager:
```bash
echo -n "YOUR_GEMINI_API_KEY" | gcloud secrets create GEMINI_API_KEY --data-file=-
```

### Step 2: Build & Deploy to Google Cloud Run
Build the container and deploy the service:
```bash
# Build and deploy directly via source
gcloud run deploy aura-sanctuary \
  --source . \
  --platform managed \
  --region asia-southeast1 \
  --allow-unauthenticated \
  --set-secrets GEMINI_API_KEY=GEMINI_API_KEY:latest \
  --port 3000
```

### Step 3: Apply Mandatory Challenge Campaign Resource Label
To register your deployment for automated challenge verification:
```bash
gcloud run services update aura-sanctuary \
  --update-labels=dev-tutorial=cloud-run-ai-challenge \
  --region=asia-southeast1
```
